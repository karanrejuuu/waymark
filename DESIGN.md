# DESIGN.md — Waymark Design System

## Visual World: Tactical Wholesale Logistics
- **Theme:** High-craft tactile Indian commerce. Evokes physical dispatch ledgers, carbon-copy challan books, painted tempo trucks, and kirana counters.
- **Canvas:** `#FAF8F5` (Warm Cream Canvas) / `#FFFFFF` (Surface Paper) / `#0F172A` (Deep Carbon Ink).
- **Accents:**
  - Turmeric Gold: `#D97706` (Border: `#F59E0B`, Subtle: `#FEF3C7`)
  - Deep Emerald: `#059669` (Dark: `#065F46`, Soft: `#ECFDF5`)
  - Vermilion Red: `#DC2626` (Soft: `#FEF2F2`)
  - Muted Ink: `#475569` (Tertiary: `#64748B`)
- **Typography:**
  - Headings: Bricolage Grotesque / Bold Display (`font-heading`, `font-extrabold`, `text-wrap: balance`).
  - Body: Plus Jakarta Sans / Inter / System Sans (`text-base`, minimum 14px for body, minimum 12px for micro-metadata).
  - Data / Ledgers: Tabular numbers (`tabular-nums`, high-contrast).
- **Rules (Impeccable Compliance):**
  - No icon tile stacks (no rounded icon squares hovering directly over headings).
  - No nested cards (flatten containers with generous spacing and hairline dividers).
  - Minimum text size: 12px for functional labels, 14px-16px for body.
  - Contrast: Minimum 4.5:1 for body copy and functional elements.
  - Motion: Purposeful kinematic feedback (route vehicle advancement, tactile challan stamp, synthetic audio click).
